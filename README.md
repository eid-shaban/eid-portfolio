# Eid Shaban · GIS & GeoAI Portfolio

Personal portfolio site for a GIS specialist and analyst. A single static `index.html` (English/Arabic, RTL-ready), no build step.

- Edit content in the data block at the top of the `<script>` in `index.html` (`T`, `SKILLS`, `PROJECTS`, `EXPERIENCE`, `CHANNELS`).
- Deploy: import this repository in Vercel (framework preset "Other"); every push to `main` redeploys.
